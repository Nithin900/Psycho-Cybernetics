## Publishing

The site is plain static HTML with no build step. To publish it with GitHub Pages: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder `/ (root)`**. It then appears at `https://nithin900.github.io/psycho-cybernetics/`.

All pages are summaries for personal study. Short quotes are from the books named on each page.
