# Psycho-Cybernetics

Study pages on Maxwell Maltz's Psycho-Cybernetics books. Each page is a single HTML file: open it in any browser. Start at [`index.html`](index.html), which lists every page by book.

| Page | Book | What it is |
|---|---|---|
| [`index.html`](index.html) | All | **Home**: every page in one place, grouped by book |
| [`self-image-day.html`](self-image-day.html) | *Psycho-Cybernetics & Self-Fulfillment* (1970) | **Self-Image Day**: an activity page of seven exercises from the book (morning mirror, Loser's List to Winner's List, the double feature, the 13 dual forces of YOUR SELF IMAGE, the four points against a resentment, two quiet minutes, and the evening NOT GUILTY verdict). Entries are saved in your browser |
| [`self-fulfillment-reading-guide.html`](self-fulfillment-reading-guide.html) | *Psycho-Cybernetics & Self-Fulfillment* | **Reading guide**: the book chapter by chapter, Part Two grouped by idea, the threads through the book, and check-yourself questions |
| [`self-fulfillment-reference.html`](self-fulfillment-reference.html) | *Psycho-Cybernetics & Self-Fulfillment* | **Reference**: all 35 Q&A topics, a glossary of Maltz's terms, the 11 spelled-out word lists, and an index of 53 stories, with page numbers |
| [`psycho-cybernetics-notes.html`](psycho-cybernetics-notes.html) | *Psycho-Cybernetics* (1960) | **Notes**: the 15 principles from theory to practice, SUCCESS vs FAILURE, a daily routine, the four rational questions, *Creative Living for Today*, an evidence check and a reading list |
| [`chapter-2-success-mechanism.html`](chapter-2-success-mechanism.html) | *Psycho-Cybernetics* | **Chapter 2 Report**: "Discovering the Success Mechanism Within You" |
| [`self-image-code-podcast.html`](self-image-code-podcast.html) | *Psycho-Cybernetics* | **The Self-Image Code**: a two-host podcast script on Maltz's tools and the research behind them |
| [`live-free-workbook.html`](live-free-workbook.html) | *Live and Be Free Thru Psycho-Cybernetics* (1975) | **Live Free Workbook**: Chapter 27, "Exercises and Techniques", with a 15-minute routine, 12 tools, phrases for feelings, a word list and a 21-day tracker |

The *Self-Fulfillment* pages use the Bantam 1973 edition; page numbers refer to it. The scanned copy used skips page 3 and pages 5–10 (the opening of Chapter 1).

## Publishing

The site is plain static HTML with no build step. To publish it with GitHub Pages: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder `/ (root)`**. It then appears at `https://nithin900.github.io/psycho-cybernetics/`.

All pages are summaries for personal study. Short quotes are from the books named on each page.
